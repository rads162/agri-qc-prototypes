State admin settings (simulated)

Every paper below reaches the firm in its firm portal (UXD-228). Which of them also go to the firm's registered mobile by SMS is set by the State admin in the state admin portal; tick to switch SMS on.

One-time code from the shop (UXD-234): where the person present confirms with a code sent to the licence holder's registered mobile; tick to ask it. Never blocks: without the code a reason is recorded.

eSign links (UXD-240, UXD-241): each link is valid for day(s); after unanswered link(s) the inspector records the response. The link always goes to the firm portal and by SMS.
